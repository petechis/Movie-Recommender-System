## 🧠 **Projektübersicht**

Dieses Projekt implementiert ein **inhaltsbasiertes Film-Empfehlungssystem**, das Nutzern Filme auf Basis **semantischer Ähnlichkeiten von Metadaten** empfiehlt.

Der Fokus liegt auf **technischer Transparenz**, **ML-Engineering-Best-Practices** und einer klaren Trennung von **Modell, Logik und UI**.

---

## 🎯 **Ziel & Motivation**

- Anwendung moderner **Machine-Learning-Verfahren**
- Aufbau eines **Content-Based Recommender Systems**
- Demonstration eines produktionsnahen ML-Workflows
- Übertragbarkeit auf andere Branchen

---

## ⚙️ **Funktionsweise**

### 🧮 **Algorithmus: Content-Based Filtering**

* Analyse von Filmmerkmalen (Genre, Inhalt, Metadaten)
* NLP-basierte Vektorisierung
* Ähnlichkeitsberechnung mit Cosine Similarity
* Top-N-Empfehlungen in Echtzeit

---

## 🔑 **Zentrale Variablen**

* **movies.pkl** – Filmdaten
* **likeness.pkl** – Ähnlichkeitsmatrix
* **movie_index** – Lookup-Index
* **distances** – Ähnlichkeitswerte

---

## 🧭 **Navigation der App**

1. Film auswählen
2. Empfehlung starten
3. Ähnliche Filme entdecken
4. Poster via API abrufen
